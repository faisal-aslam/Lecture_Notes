% ============================================================
% Master file: assembles the whole lecture series into one
% combined "book" with a single table of contents at the front
% and each lecture appearing as a "Lesson N: <title>" chapter.
%
% How this works:
%   - Each lectureN-*.tex file is still a fully independent,
%     standalone document (own title page, own table of
%     contents) -- it just now gets its actual content from
%     content/lectureN-*-body.tex via \input, instead of
%     writing that content inline.
%   - This file (full-course-notes.tex) \input's the exact same
%     body files directly, wrapped in \chapter{Lesson N: ...}
%     headings, under the `book` class. That gives one global,
%     accurate table of contents (with real page numbers) and
%     per-lesson section numbering like "2.1, 2.2, ..." -- no
%     manual page-range bookkeeping, and nothing to keep in
%     sync by hand.
%   - Individual lectureN-*.tex files must still be compiled at
%     least once if OTHER lectures cross-reference them via
%     xr-hyper (\externaldocument) -- see lecture-preamble.tex.
%     This file does not need that: since all content lives in
%     one document here, \ref resolves locally.
%
% Usage:
%   pdflatex full-course-notes.tex   (run twice, for the ToC
%   and cross-references to settle -- compile_all.sh does this)
% ============================================================
\documentclass[11pt,a4paper,oneside]{book}

% Chapter headings read as plain "Lesson N: Title" -- no
% automatically-prepended "Chapter N" text. \chapter still

% "2.1", "2.2", ... within Lesson 2, and each chapter still
% gets a correct, numbered table-of-contents entry) -- only the
% on-page *display* is customized here.
